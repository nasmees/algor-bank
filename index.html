About

algor-bank คือ CLI บริหารสหกรณ์อิสลามแบบ local-first ออกแบบให้รู้สึกเหมือนเครื่องมือ mainframe สมัยใหม่ (แนว Zowe CLI) — พิมพ์คำสั่ง จัดการสมาชิก บัญชี และสัญญาการเงินตามหลักชารีอะฮ์

ไม่มีดอกเบี้ย (Riba) · แบ่งกำไร-ขาดทุน (PLS) · ผลิตภัณฑ์ Murabaha / Mudarabah / Musharakah / Ijarah / Qard Hasan ข้อมูลเก็บในเครื่อง + สำรองเป็นไฟล์ .vault เข้ารหัส AES-256-GCM

“members · accounts · sharia finance · vault · riba-free”

เหมาะกับการศึกษาและทดลองระบบสหกรณ์ — ไม่ทดแทนระบบบัญชีที่จดทะเบียนตามกฎหมายหรือมติ Sharia Board จริง

algor-bank is a local-first Islamic cooperative banking CLI with a modern mainframe feel (Zowe CLI style) — type commands to manage members, accounts, and sharia-compliant contracts.

No Riba · Profit & Loss Sharing · Murabaha / Mudarabah / Musharakah / Ijarah / Qard Hasan. Data stays on device; optional AES-256-GCM .vault backups.

“members · accounts · sharia finance · vault · riba-free”

Built for learning and ops practice — not a replacement for licensed cooperative systems or a formal Sharia Board.

Step-by-step guide

1) เปิดระบบและเลือกภาษา

1) Launch and choose language

▶ เปิด algor-bank-islamic-coop.html
Welcome to algor-bank!
Select language
  1 th   2 en
algor> 1

พิมพ์ 1 สำหรับไทย หรือ 2 สำหรับ English

Type 1 for Thai or 2 for English

2) เข้าสู่ระบบ (OPS)

2) Sign in (OPS)

algor> LOGIN admin admin123
✓ LOGIN admin · role ADMIN

บัญชีตัวอย่าง: admin/admin123 (เต็ม) · teller/teller123 (ทำรายการ) · viewer/view123 (อ่านอย่างเดียว)

Demo users: admin/admin123 (full) · teller/teller123 (ops) · viewer/view123 (read-only)

3) โหลดข้อมูลตัวอย่าง

3) Load sample data

algor> SEED
✓ โหลดข้อมูลตัวอย่างสำเร็จ
algor> STATUS

ถ้ามีข้อมูลอยู่แล้วใช้ SEED FORCE เพื่อโหลดทับ

If data already exists, use SEED FORCE to reload

4) สมาชิก — ดู / เพิ่ม / แก้ไข

4) Members — list / add / edit

algor> MEMBER LIST
algor> MEMBER ADD ยูซุฟ บิน อะหมัด 081-111-2222
algor> MEMBER M001
algor> MEMBER EDIT M001 phone=089-999-8888 address=ปัตตานี
algor> MEMBER SEARCH ยูซุฟ

ใน Panel (F7) มีช่องค้นหาและปุ่มแก้ไขได้เช่นกัน

The F7 panel also supports search and inline edit

5) เปิดบัญชีและฝาก–ถอน

5) Open account and deposit / withdraw

algor> ACCOUNT OPEN M001 SAVINGS 5000
algor> ACCOUNT LIST
algor> DEPOSIT A001 1000 เงินเดือน
algor> WITHDRAW A001 200
algor> RECEIPT T00x

ประเภทบัญชี: SAVINGS · SHARE · INVEST · หลังทำรายการใช้ RECEIPT พิมพ์สลิป

Account types: SAVINGS · SHARE · INVEST · use RECEIPT to print a slip

6) สินเชื่อชารีอะฮ์

6) Sharia finance

algor> FINANCE APPLY M001 MURABAHA 50000 12 5
algor> FINANCE APPROVE F001
algor> FINANCE PAY F001 5000
algor> FINANCE LIST

ผลิตภัณฑ์: MURABAHA · MUDARABAH · MUSHARAKAH · IJARAH · QARD

Products: MURABAHA · MUDARABAH · MUSHARAKAH · IJARAH · QARD

7) สำรองข้อมูลเข้ารหัส (Vault)

7) Encrypted backup (Vault)

algor> SETPASS my-secret-pass
algor> VAULT SAVE
algor> VAULT LOAD
algor> LOCK

รหัสผ่านอยู่ใน memory เท่านั้น · ลืมรหัส = ถอด .vault ไม่ได้ · ระบบจะเตือนถ้ายังไม่ SAVE นาน

Password stays in memory only · lost password = cannot decrypt · reminders if you delay SAVE

8) นำเข้าสมาชิกจาก CSV

8) Import members from CSV

name,phone,address,id
อับดุลลอฮ์,081-111-1111,ปัตตานี,
ฟาติมะฮ์,082-222-2222,ยะลา,M010

algor> CSV

หรือกด CSV Import ในแท็บ Members ของ Panel (F7)

Or use CSV Import on the Members tab in the F7 panel

Quick start

  1. กด เปิด algor-bank (หรือเปิด algor-bank-islamic-coop.html)
  2. Click Launch algor-bank (or open algor-bank-islamic-coop.html)
  3. เลือกภาษา — 1 ไทย / 2 English
  4. Choose language — 1 Thai / 2 English
  5. LOGIN admin admin123 แล้ว SEED
  6. LOGIN admin admin123 then SEED
  7. ลอง STATUS · MEMBER LIST · ACCOUNT LIST · FINANCE LIST
  8. Try STATUS · MEMBER LIST · ACCOUNT LIST · FINANCE LIST
  9. SETPASS … แล้ว VAULT SAVE เพื่อสำรองเข้ารหัส
  10. SETPASS … then VAULT SAVE for encrypted backup
  11. กด F7 สำหรับ Panel หรือ HELP สำหรับคำสั่งเต็ม
  12. Press F7 for Panel or HELP for the full command list

ความปลอดภัยและข้อจำกัด

Security & limits

AES-256-GCM · PBKDF2 120k rounds · Web Crypto API

  • รหัสผ่าน vault ไม่ถูกเขียนลงดิสก์ — ต้องใส่ทุกครั้งที่ LOAD
  • ลืมรหัสผ่าน = กู้ไฟล์ .vault ไม่ได้
  • LOCK ล้างรหัสออกจากหน่วยความจำเมื่อเดินจากเครื่อง
  • รันออฟไลน์ได้หลังโหลดหน้า
  • Vault password is never written to disk — required on every LOAD
  • Lost password = .vault cannot be recovered
  • LOCK clears the password from memory when you step away
  • Works offline after the page has loaded
ข้อจำกัด: เครื่องมือศึกษาและทดลองระบบสหกรณ์อิสลาม ไม่ทดแทนระบบบัญชีที่จดทะเบียนตามกฎหมายไทย และควรมีที่ปรึกษาชารีอะฮ์เมื่อใช้งานจริง
